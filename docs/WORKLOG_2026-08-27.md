## 4. "왜 자꾸 실수하냐"는 질문 — 원인을 되짚었다

사용자가 이 사고를 보고 반복되는 이유를 물었다. 정리한 답은 둘이다.

1. **계획 실행 단계로 넘어가면 관성이 붙는다.** 조사 단계에서 파일의 손 댓글도 봤고
   `existing()`이 `JSON.parse`를 쓴다는 것도 읽었는데, 실행 직전에 그 둘을 다시 맞대어
   보지 않았다. 조사가 꼼꼼했다는 사실 자체가 실행을 덜 의심하게 만들었다.
2. **세션을 넘어 남는 습관이 없다.** CLAUDE.md·memory에 적힌 글자만 남고, 그마저 대개
   "이번엔 이렇게 하지 마라"는 사례별 패치이지 "관찰한 것을 실행 직전에 항상 재대조한다"는
   일반 규율로 옮겨지진 않는다. 그래서 같은 모양의 실수는 막아도 다른 옷을 입은 같은
   종류의 실수는 다시 뚫린다.

이어서 사용자가 "그래서 CLAUDE.md·작업내용·memory를 기록하라고 했는데 안 읽는 거냐"고
물었다. 확인해 보니:

- **CLAUDE.md·MEMORY.md는 실제로 매 세션 강제로 컨텍스트에 실린다** — 안 읽는 게 아니다.
- **하지만 WORKLOG("작업내용")는 자동으로 안 실리고, 08-21-2 이후로 하나도 안 쓰였다.**
  일주일치(신고 채널·해몽 사전 확장·도메인 사고·오늘 이 배치)가 기록 없이 흘렀다.
- 읽는 것과 실행 순간에 그것을 다시 불러와 대조하는 것은 별개라는 것도 함께 짚었다.

사용자가 "무조건 쓰라"고 확정했다. 이 파일이 그 재개다.

### 5.1 자동 시험이 놓칠 뻔한 결함 — ko/en이 "똑같이 틀려도" 통과한다

새 문맥 11개의 ko/en 짝을 `verify-dream-context-parity`에 추가해 전부 통과시켰는데, 그
시험은 **두 언어가 같은 뜻을 고르는지만 보지 그 뜻이 실제로 맞는지는 안 본다.** 통과
확인 후 손으로 "산에 올랐다가 굴러떨어졌다"를 따로 돌려 보니 ko·en 둘 다 기존

시험은 초록불이었다.

원인은 기존 "산 정상에 오름"의 매칭 키가 "올랐"·"올라갔"처럼 흔한 동사 어간이었던 것 —
"오르다가 떨어졌다"처럼 두 동작이 한 문장에 있으면 새 문맥과 동점이 나 대표 의미가 늘
이겼다. "정상"을 반드시 언급해야 걸리도록 좁혀 고쳤다(ko "정상에·정상까지·꼭대기까지·
정상을", en "peak summit" — 둘 다 원래 "climb"/"올랐"처럼 과하게 넓은 낱말을 썼었다).

**시험을 통과한 뒤에도 손으로 한 번 더 돌려 본 것**이 이번엔 맞아떨어졌다 — 자동 시험의

## 14. 클렌징 — 매칭 결함 (a)·(b)를 정리했다

사용자가 "지금 클렌징부터"를 골랐다. `scripts/cleanse-dream-alias-gaps.mjs`로 (a)를,
`engines/dream-match.ts` 직접 수정으로 (b)를 시도했다.

### 14.1 EN 키워드 own-term 누출 — "쥐"에서 찾은 것과 같은 종류를 6개 더 찾았다

`term_en`이 "A / B"인 다중의미 상징을 전수로 훑어(ox·marriage·grave·ancestor·monk·
god·stone·letter·apple, rat·wine은 이미 고쳤음) 실제로 동점이 나는지 손으로 시험했다.
**확인된 버그 넷**을 고쳤다 — own-term 필터가 "A / B" 문자열 전체만 보고 "A"·"B" 낱말
자체는 못 걸러서, 그 낱말이 기존 의미의 영어 키워드에 남아 있으면 아무 문장에나 공짜
점수를 줬다.

```
"an ox gored me"                    → 잘못 "살진 소"(existing) — "ox"가 공짜 점수
"I mailed a letter"                 → 잘못 "편지를 받음"(existing) — "letter"가 공짜 점수
"I attended a friend's wedding"     → 잘못 "본인의 결혼"(existing) — "wedding"이 공짜 점수
"a monk was reading"                → 애매하게 "스님이 가르침을 줌" — "monk"가 공짜 점수
```

ox·letter·marriage·monk의 기존 키워드에서 상징 이름과 겹치는 낱말을 뺐다. grave·stone·
apple은 실제 동점까지는 안 갔지만 같은 위험이 있어 예방적으로 함께 정리했다.

### 14.2 (a) 별칭 공백 — 동형이의어 충돌을 손으로 시험한 뒤에만 채웠다

`isStandalone`의 경계 검사(조사 뒤따르면 통과, 아니면 합성어로 봄)를 후보마다 직접
시뮬레이션해 실측했다.

```
채운 것    눈동자·눈알(eye) · 금·보석(gold) · 조상(ancestor) · 대통령(president) ·
           돌(stone) · 신랑·신부(bride-groom)
안 채운 것  임금(급여와 충돌) · 절(절하다와 충돌) · 사원(회사원과 충돌) ·
           뼈(관용구 "뼈를 깎는 노력"과 충돌) · 신 단독(신나다) · 머리 단독(두통) ·
           차 단독(원래도 의도적으로 뺌)
```

대조군("금지된 행동"·"요금을 냈다"·"아이의 돌잔치"·"첫돌"·"임금이 올랐다" 등)으로
전부 안 걸리는 것도 함께 확인했다.

### 14.3 (b) PARTICLES에 어미를 넣어 봤다가 되돌렸다 — 가장 중요한 발견

조사만 담던 `PARTICLES`에 "다"·"어요"·"아요"·"았"·"었"·"였"·"던"을 추가해 봤다.
`verify-dream-match.ts`를 돌리자 **기존 시험은 전부 통과**했지만, 손으로 더 넓게
대조군을 만들어 보니 **새 오탐 다섯 건**이 나왔다:

```
"말았다"(그만두다)         → 말(馬)
"새었다"(날이 새다)        → 새(鳥)
"개었다"(날이 개다)        → 개(犬)
"물건을 집었다"            → 집(家)
"라면이 불었다"            → 불(火)
"하지 말다"·"가스가 새다"·"물건을 집다" 등 사전형도 같은 문제
```

한 음절 상징이 예순 개나 되는데 그 상당수가 이런 동형이의어 동사 어간과 겹친다 —
**기존 시험(FIRST_SYLLABLE_TRAPS)이 통과했다고 안전하다는 뜻이 아니었다.** 그 시험은
정해진 표본만 보고, 내가 고치려던 자리(말다·새다·개다·집다·불다)는 애초에 표본에
없었다. **전부 되돌렸다** — `PARTICLES`는 조사만 담아야 안전하다는 원래 설계가 맞았다.

대신 안 걸리던 문장이 실제로 쓸 법한 **완전한 활용형을 상징별 `aliases`에 직접
올리는** 쪽으로 갔다 — 엔진을 안 건드리므로 다른 상징에 영향이 없다.

```
tooth-fall  "이가 빠졌다"       marriage  "결혼했다"·"결혼했어요"
bathing     "씻었다"           naked     "벌거벗었다"
flying      "날았다"           spider    "거미줄"(합성어라 별개 원인)
```

### 14.4 결과 — 기존 결함 5건이 전부 사라졌다

이 다섯은 오늘 배치 이전부터 있던, 이 세션과 무관한 기존 결함이었다(거미·이·
벌거벗음×2·날다). 클렌징하며 손을 대다 보니 전부 고쳐졌다.

```
verify-dream-context-parity   실패 0건(기존 5건 포함 전부 통과)
verify-dream-match             ALL PASS
verify-guide-numbers           ALL PASS
tsc                            0건
dreamslink build               성공
```

### 14.5 아직 남은 것

- (a) 남은 후보: 절·사원·뼈·해골(부분)·차·기차 놓침·신(단독)·머리카락(단독) — 전부
  동형이의어 충돌이 실측으로 확인돼 의도적으로 남겨 둔 것.
- (b) `PARTICLES`는 건드리지 않기로 확정했다 — 다음에 비슷한 "활용형이 안 걸림" 결함이
  나오면 이번처럼 상징별 `aliases`에 완전한 활용형을 올리는 쪽으로 갈 것.
- `term_en`에 "/"가 있는 **단일 의미** 상징(insect·exam·boat·watch·road 등)은 안
  훑었다 — 의미가 하나뿐이면 discrimination이 없어 이 버그가 발현되지 않는다.
