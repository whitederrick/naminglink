## 1. 허브 아코디언 (미커밋)

사전 82편(천간 10 · 지지 12 · 일주 60)이 허브 카드 목록에 섞여 원리 안내가 묻혔다. `guide-index.ts` 에 `group`
(`stems`·`branches`·`pillars`)을 문서의 `type` 기준으로 적고(슬러그 접두 판정 금지), 허브 아래쪽에 `<details>` 셋
(기본 접힘, 제목 = 묶음 첫 문서의 `eyebrow` + 편수). `guide-back.ts` 의 순서표는 위쪽 카드만 센다.
서버 응답 기준 확인: `/ko/guide` 200 · `<details>` 3 · open 0 · 고유 문서 링크 92. **눈으로 하는 확인(2열 펼침 ·
다크모드 · 문서 → 「이전 화면으로」)은 사용자 몫으로 남았다.**

## 2. 입문 문서 `saju-letters` + 허브 도입 (미커밋)

사용자 지적: 「천간·지지·일주를 모르면 이해하기 어렵다」. 기존 `natal-chart` 가 최소 정의만 갖고, 천간 10글자 소개와
일주 60가지(육십갑자) 설명이 비어 있었다.

- **새 문서** `guide/saju-letters` (한 편, 절 4개 · 표 2개): 천간 10(오행·음양 표) · 지지 12(띠 표) · 일주 60(양 천간은
  양 지지와만 짝). 허브 목록 맨 앞에 등록. 한·영 원문은 `docs/drafts/D-letters/skeleton.{ko,en}.json`.
- **표 값은 번역하지 않는다.** 천간 표는 각 로케일 `guide/stem-gap` 의 십신 표 앞 두 칸, 지지 표는 `guide/zodiac` 첫 표,
  `backLabel` 은 `stem-gap` 것을 글자 그대로 쓴다(`extract-fill.mts`). 표가 기존 문서와 어긋날 자리가 없다.
- **허브 도입**: `guide` 문서 `sections` 맨 앞에 한 절(도입 문단 + 사전 셋 설명 목록). 사전 이름은 각 사전 문서의
  `eyebrow` 로 토큰(`{{E1}}`~`{{E3}}`)을 채운다(`build-hub.mjs`). 허브 아코디언 제목 밑 설명 대신 위쪽 목록으로 했다.
- **번역**: 현재 세션의 Claude 에이전트 셋(언어 7개씩) → 독립 검토 셋(고침 본문 약 110잎 · 허브 약 30잎, 대부분 기존
  문서 용어에 맞춘 것) → `merge-fixes.mjs` → 21개 언어 삽입. OpenAI 호출 없음.
- **부수 효과**: 홈 화면 안내 카드는 목록 앞 4편이라 `saju-letters` 가 첫 카드가 되고 `ten-gods` 가 밀려난다.
