## 1. 사주링크 — 완료된 것

### ⑤ 리포트 장수를 구조로 고정 (커밋 `8138a90`)

고시의 5장·7장이 **선언된 `Page` 수가 아니라 글이 넘쳐서** 나오던 값이었다. 해설이 짧으면
4장·6장으로 나갔고, **팔던 5장 중 하나는 개인정보 안내 세 줄뿐인 빈 장**이었다.

→ 장 구성을 실제 내용으로 다시 짜서 **바닥은 구조(선언된 Page), 천장은 상한(`LIMITS`)**.
해설이 실패해도 엔진 서술이 같은 자리를 채운다.

### ⑥ 약관을 실제 상품과 맞춤 (커밋 `af120ab`)

약관 4종이 아직 **인연링크 궁합 서비스**를 팔고 있었다 — 서비스명이 「인연링크」, 「두 사람의
관계」·「매칭률」, 엔진에 없는 **대운·세운**. ko·en을 사주로 다시 쓰고 AI 고지를 넣었다.

**살아 있던 고지 위반 하나**: `getRequestLocale`이 접속 국가로 23개 로케일 아무거나 골라,
화면은 영어인데 **약관만 그 언어의 궁합 약관**이 나갔다. `translatedLocales`로 좁혔다.

### ⑦ 로케일 (커밋 `65fc18f`·`39e64e1`·`05123b7`)

**화면 사전 23개 · 약관 23개 완료.** 검사기 전부 통과.

핵심은 **재사용**이다 — 사주 잎 403개 중 **204개(51%)가 인연링크와 en 원문이 글자까지 같다**
(오행·띠·일간·십신 이름, footer 16개, 언어 선택기, 폼 라벨). 처음에는 그걸 전부 다시
번역시켜 호출이 두 배가 됐고, 한도에 걸려 **`id` 로케일이 141개나 영어로 남은 채 "성공"**했다.
`export-dictionaries.ts`(인연링크) → `translate-i18n.ts`가 **en이 같은 자리만** 물려받는다.

## 2. 상품 개편 — 2026-08-05 결정

### 무엇을 왜 바꾸는가

- **사주와 오늘의 운세는 다른 것이다.** 사주는 평생, 오늘의 운세는 그 사주에 오늘 일진을 대 본
  하루짜리다. 그런데 「삶의 네 영역」이 **오늘 십신**으로 매긴 값이면서 "내 사주의 성향"으로
  읽혔고, 보관하는 문서의 40%가 하루짜리였다.
- **총운/프리미엄의 차이가 근거 숫자 두 장뿐**이라 팔 이유가 약했다.

### 확정된 것

| | |
| --- | --- |
| 상품 | **「평생 사주와 올해의 운세 리포트」 하나.** ₩990 / US$1.99 |
| 가격 근거 | 궁합은 상대가 바뀌면 재구매하지만 **사주는 1인 1회**. 무료로 주는 곳도 있어 기준선이 낮다 |
| PDF | **평생 + 올해 총운.** 오늘의 운세는 넣지 않는다 |
| 무료 화면 | 개략만 — 원국·일간 한 줄·오행 막대. **강약·용신·십신·영역은 유료** |
| 오늘의 운세 | 무료·화면 전용 + **형제 서비스 채널**(셀프 광고) |
| 해설 | 엔진 템플릿이 본편, **AI는 요약 한 문단**만 |
| 고지 | 참고자료 고지 + **AI 문단 고지**를 자리와 문장을 나눠서 |

### 왜 AI를 한 문단으로 좁혔나

넓게 두면 **이용자가 읽는 글이 사실상 전부 가변**이라, 처음 요구("매번 바뀌지 않게")가
해결된 게 아니라 면책된 것이 된다. 1회 구매·평생 보관·재발급 5회 상품에서는 다르다.

더 큰 이유는 **검증**이다 — 이 영역은 과장·단정이 정책 위반인데, 매번 새로 쓰는 글은 매번
새로 위반할 수 있고 23로케일을 사람이 다 읽어 볼 수 없다. **템플릿은 한 번 검토하면 끝난다.**

## 5. 관통 원칙

1. **고시=실제.** 약관·상품 설명은 실제 제공물(장수·기능)과 일치. 문구로 부풀리지 않는다.
2. **분량으로 장수를 만들지 않는다.** 장수는 선언된 `Page`가 정한다. 다만 **글자 수 상한은
   지면이 아니다** — 라틴 451자와 한글 451자는 두 배 넘게 차이 난다. 상한은 사전이 소리 없이
   자라지 않게 하는 신호이고, 지면은 **로케일마다 실제로 렌더해 장을 세는 것**이 정한다(③).
3. **같은 입력이면 같은 문서.** 달라져도 되는 자리는 `MUTABLE_FIELDS`에만 있고, 코드·검사기·
   고지 세 곳이 같은 목록을 본다.
4. **무료=템플릿(무과금)·유료=엔진+AI 한 문단.** 고트래픽·SEO·애드센스 속도 보호.
5. **결정론.** 점수·간지는 엔진. 과잉약속 회피(운명·건강 단정 금지).
6. **복제 앱은 전수 grep — 라틴과 한글을 함께.** 2026-08-05에 한글 "인연"을 놓쳐 꼬리글이
   `Saju-Link ( 인연 링크 )`로 배포됐다.
7. **새로 만들기 전에 형제 앱을 먼저 볼 것.** 사전 잎의 51%가 이미 번역돼 있었다.
8. **검사기에는 대조군을 넣는다.** 늘 통과하는 검사기는 없는 것과 같다.
9. **green에서만 커밋.** 라이브 표는 후방호환 마이그레이션 + 두 앱 빌드 확인 후에만.
