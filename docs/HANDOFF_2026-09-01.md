## 4. 다음에 할 일 (우선순위 순)

### 1) 밀러 나머지 — **`Calm`부터**

남은 **1,936개**. `Abortion`·`Absalom`·`Barrel`은 앞서 걸러진 것이므로 건너뛴다.

**절차는 고정이다. 오늘 한 단계를 더했다.**

```
① 20개 이하로 쪼갠다
② 원문에서 뽑아 apps/dreamslink/data-sources/extract/m<n>.json 으로 쓴다
③ node scripts/verify-dream-cite.mjs <그 파일>            (인용 진위)
④ 커버리지 대조 — 입력 표제어 ↔ 결과 cite.locator          (빠뜨림)
⑤ 인종·민감 표현 grep
⑥ 새 상징의 매칭 키를 kmm<n>.json 에 쓴다
⑦ node scripts/build-dream-dictionary-v2.mjs
   node scripts/build-dream-match-tables-v2.mjs            ← 반드시 둘 다. 앞것만 돌리면
                                                             별칭이 통째로 날아간다
⑧ node scripts/verify-dream-km.mjs
   apps/dreamslink 에서 tsx scripts/audit-km-dead-words.mts
⑨ ★ 자연스러운 문장을 matchDream 에 직접 넣어 새 상징이 실제로 걸리는지 본다
     — 오늘 ⑧까지 전부 초록불인데 다섯 상징이 하나도 안 걸렸다(§18)
```

**⑥에서 지킬 것** (오늘 검사기가 22건 + 18건을 잡았다)

- 판별어에 **그 상징의 이름을 그대로** 넣지 않는다
- 형제 의미끼리 낱말을 **공유하거나 부분 문자열로 겹치지** 않게 한다
- **한 글자 한국어**(썰·갓·쉰·한·하·탔·꿀·뜯)는 엔진이 안 센다. 두 글자로
- **이미 별칭인 낱말**(buried·cablegram·cackling·hens·fresh)은 판별어로 쓸 수 없다
- 영어 짧은 낱말(one·with·a)도 안 센다
- **별칭은 어간이 아니라 완전한 활용형으로.** `데었`이 아니라 `데었다`·`데어서`.
  `dream-match.ts`의 `PARTICLES`는 조사만 담는다(어미를 넣었다가 「말았다」가 말(馬)로
  걸리는 오탐이 나서 되돌린 자리다)

**제외하는 것**: 참조 지시(`[29] See Funeral`), 조언 문장(`Beware of writing letters`),
조짐이 아닌 이론·태도 서술.

밀러가 넓어지면 parity가 건너뛰는 **43쌍**(자동차·열쇠·거미·사과 등)이 따라 준다.
