### 🔴 B. 표시 광고를 닫을 수 없는 모달 게이트에 넣었다 — 애드센스 정책 위험

`apps/naminglink/src/components/NamingForm.tsx:1035-1065`

```tsx

  …
  <AdBanner variant="leaderboard" slotKey="analysis_wait" … />
  …  10~15초 카운트다운
```

제출 버튼 문구도 "**광고 확인 후** 분석 시작"이고, 모달 안 문구는 "광고와 한자 분석을 함께

전면 오버레이 안에 있다.

구글 정책에서 이 둘은 각각 걸린다.

- **오버레이·팝업 게재**: 애드센스 표시 광고를 페이지 위에 뜨는 상자 안에 넣는 것
- **보상·유인 시청**: 표시 광고를 콘텐츠 해제 대가로 쓰는 것. 보상형은 GAM·AdMob의
  **보상형 포맷으로만** 허용된다

사용자가 붙여 준 애드센스 안내의 "**사이트에 정책 위반사항이 있는 경우**" 항목이 정확히 이
자리를 가리킬 수 있다. 심사 통과 여부에 직접 영향을 주고, 승인 후에 걸리면 계정 단위 조치가 된다.

**구조 자체는 이미 답을 갖고 있다** — `docs/WORKLOG_2026-07-30.md` §4가 "진입=오퍼월,
후보 열기=GAM 보상형"으로 정해 두었다. 게이트의 대가를 **표시 광고가 아니라 오퍼월·GAM
보상형이 맡고**, 애드센스 표시 광고는 모달 밖 일반 자리로 내리면 정책과 어긋나지 않는다.

## 4. 감사 뒤에 추가로 찾은 결함

감사를 마친 뒤 조치를 진행하면서 두 건이 더 나왔다. 둘 다 **브라우저에서 실제로 재서** 찾았다.

### 🔴 K. 광고 `<ins>` **안쪽**에서 폭이 새어 화면이 밀려났다

2026-07-29에 `!max-w-full`로 고친 것으로 끝난 줄 알았으나, 그것은 `<ins>` **자신의** 폭만
막는다. 애드센스는 `<ins>` 안에 소재 크기 그대로의 div+iframe을 넣는데, 그 본질 폭
(min-content)이 조상으로 올라간다. 바깥 상자의 `overflow-hidden`은 **보이는 것만** 자르고
폭 계산은 막지 못한다.

운영 실측(뷰포트 395, 광고 로드된 상태):

```
INS w=437  (…!max-w-full)          ← 우리 클래스가 잡은 값
 └ DIV    w=831                    ← 애드센스가 넣음
   └ IFRAME w=831
결과: 문서 457 vs 뷰포트 395 → 오른쪽이 잘리고 화면이 좌우로 밀린다
```

`<ins>`에 `[contain:inline-size]`를 더해 끊었다. 처방 후 문서 395·헤더 355·광고상자 355×50
(**높이 불변**). 두 앱 모두 적용.

**재현 조건을 기록해 둔다** — 헤드리스로는 광고가 `unfilled`이라 831짜리가 생기지 않아
끝까지 재현되지 않았다. 폭 12개·화면 7개를 훑어도 전부 0이었다. 실제 브라우저 콘솔에서
재고 나서야 원인이 나왔다. **광고가 얽힌 레이아웃 문제는 헤드리스 측정으로 "없음"을
결론 내리면 안 된다.**

또한 이 과정에서 `--window-size`만 준 헤드리스 촬영이 `<meta viewport>`를 무시해 실제와
다른 화면을 만든다는 것을 확인했다. 그 그림을 근거로 "푸터가 가로로 넘친다"고 잘못
보고한 적이 있다 — **모바일 확인은 반드시 기기 에뮬레이션으로 할 것.**

### 🟠 L. 언어 선택기가 랜딩에만 있었다

언어는 접속 국가로 정해지는데(§2 C), 판정이 어긋난 사람이 바꿀 수단이 랜딩에만 있었다.
검색·광고·공유 링크로 서비스 화면에 곧바로 들어오면 그 화면에 갇힌다.

"서비스 약속"의 `기본 언어: KO` 칩을 선택기로 바꿔 해결했다(사용자 제안 — 화면 구조를
바꾸지 않는다). 경로와 쿼리를 유지하며 언어만 갈아 끼운다.

### 🟡 M. 상단 배너가 버튼과 12px 붙어 있었다

PC에서만 버튼과 광고를 좌우로 갈랐는데, 마지막 버튼과 광고 사이가 12px뿐이었다(실측).
애드센스는 오클릭을 계정 정지 사유로 본다. 광고 → 버튼 → 구분선 순서로 세로로 쌓아
해결했다(간격 15px). 덤으로 광고 폭이 831 → 1200이 되어 970×90 리더보드를 받을 수 있다.
대가는 헤더가 128 → 183px로 높아진 것이다(사용자 결정).
