sajulink · dreamslink 웹 배경 세트

순수 CSS/SVG(래스터 이미지 0). 레티나 선명·용량 거의 0·테마 재색칠 가능·라이선스 무관. 각 패널 아래 코드 보기를 펼쳐 그대로 복사하세요. 히어로 위 텍스트/CTA는 앱에서 얹으면 됩니다. 색값은 `element_lucky_map`·브랜드 톤에 맞춰 조정 가능.

사주 — Hero

saju / 히어로 — 밤하늘 + 별 + 오행 오로라 + 한지 그레인class .saju-hero
CSS 보기
.saju-hero{
  position:relative;
  background:
    radial-gradient(1200px 300px at 80% -10%, rgba(46,139,87,.20), transparent 60%),   /* 목(청록) */
    radial-gradient(900px 300px at 10% 120%, rgba(226,59,59,.16), transparent 60%),     /* 화(적) */
    radial-gradient(700px 260px at 50% 40%, rgba(212,175,55,.10), transparent 60%),      /* 금(금) */
    linear-gradient(160deg,#0b1026 0%,#131a3a 45%,#0d1330 100%);
}
/* 별: ::before 에 radial-gradient 점들 / 한지 그레인: ::after 에 feTurbulence SVG data-URI (opacity .06, mix-blend overlay) */
/* (본 파일의 .saju-hero::before, ::after 규칙을 그대로 복사) */

해몽 — Hero

dream / 히어로 — 몽환 야간 그라데이션 + 블러 구름 오브 + 옅은 별class .dream-hero
CSS 보기
.dream-hero{
  position:relative;overflow:hidden;
  background:linear-gradient(160deg,#1a1140 0%,#3b1d63 40%,#6d3b8e 70%,#c56aa0 100%);
}
/* 구름 오브: ::before inset:-20% 에 radial-gradient 3개 + filter:blur(18px) */
/* 별: ::after radial-gradient 점들 opacity .5 */
/* (본 파일의 .dream-hero::before, ::after 규칙 복사) */

해몽 — Section

dream / 섹션 — 차분한 파스텔(본문·결과 카드)class .dream-sec
CSS 보기
.dream-sec{

활용: 히어로 섹션 <section class="saju-hero">처럼 감싸고, 다크/라이트 토글 시 gradient 색만 CSS 변수로 빼면 됩니다. 성능: 모두 GPU 합성 대상이라 가볍고, prefers-reduced-motion 사용자에겐 애니메이션 없이 정적 배경으로 안전.
