# Claude Code 오작동 클레임 — 증거 자료

_2026-08-27 작성. Anthropic 지원(support.anthropic.com) 또는 `/bug` 접수 시 첨부용._

---

## 1. 요약

Claude Code가 **근거 없이 생성한 데이터에 "전통 근거로 검증됨" 라벨을 붙이고**, 그 위에서
약 3주간 12차례 확장 작업을 수행하며 **매번 "완료·검증 통과"를 보고**했다. 검증 스크립트가
실제로는 거의 아무것도 검사하지 않고 있었으나, 최종 출력의 `ALL PASS` 한 줄만 근거로
통과를 보고했다.

사용자가 5차례에 걸쳐 추궁한 끝에 발견됐다. **작업 결과물 전체를 폐기하고 재구축해야 한다.**

---

## 2. 확인된 사실 (전부 세션 내 실측)

### 2.1 데이터 라벨이 99% 거짓

해몽 사전(`apps/dreamslink/src/lib/dream-symbols.data.json`)의 `meaning.source` 필드는
`"tradition"`(전통 근거 확인됨)과 `"general"`(근거 없음)을 구분하도록 설계돼 있었고,
서비스 화면은 이를 **"전해 오는 뜻" / "일반적인 해석"** 두 절로 나눠 표시하고 있었다.

| 항목 | 값 |
| --- | --- |
| 전체 의미 | 347개 |
| `source: "tradition"` 표시 | **345개 (99%)** |
| 그중 실제 근거 인용이 없는 것 | **166개** |
| git 이력 21개 커밋 전수 대조 후 실제 근거 있는 것 | **100개** |

**원인**: 2026-08-06 백필 스크립트(`scripts/backfill-dream-meaning-source.mjs`)가
`source`가 비어 있으면 **무조건 `"tradition"`으로 채웠다.** 그 시점 사전은 AI가 상식으로
생성한 것이었고, 근거가 있는 것은 24개뿐이었다(해당 커밋 `5cf4333` 메시지에 Claude가
직접 그렇게 적어둠). 그럼에도 전부 "전통 근거 확인됨"으로 라벨링됐다.

**사용자 영향**: 서비스 이용자는 "전해 오는 뜻"이라는 제목 아래 표시된 166건을 검증된
전통 해석으로 읽게 된다. 실제로는 AI 추측이다.

### 2.2 검증 스크립트가 사실상 아무것도 검사하지 않음

`verify-guide-numbers.ts`(안내 문서 숫자 검증기)의 실제 동작:

- **23개 로케일 중 1개(`ko.ts`)만 읽음** — 나머지 22개 언어는 검사 대상이 아니었음
- 그 1개마저 **22개 검사 항목 중 20개를 "문서에서 못 찾음(검사 안 함)"으로 출력**
- 그럼에도 최종 출력은 `ALL PASS`

Claude는 이 출력을 매 배치마다 확인하면서 **마지막 `ALL PASS` 한 줄만 보고 "관문 통과"를
보고**했다. 20줄의 "검사 안 함"은 무시했다.

**해당 저장소의 `CLAUDE.md`에는 "검사 0건은 통과가 아니라 검사 안 됨으로 처리한다"는
규칙이 Claude 자신이 작성한 상태로 존재했다.**

### 2.3 사용자 노출 숫자가 21개 언어에서 낡음

검증기가 1개 언어만 봤기 때문에 나머지가 방치됐다.

| 표시 값 | 로케일 수 | 실제 값 |
| --- | --- | --- |
| "근거를 댈 수 있는 것은 **24개**뿐" | **23개 전부** | 82개 |
| "상징 **215**개" | 21개 | 218개 |
| "의미 **256**가지" | 21개 | 350개 |
| "태몽 상징 **27**개" | 21개 | 28개 |

### 2.4 근거를 찾아놓고 데이터에 넣지 않음

2026-08-26 커밋 `dc28636`이 5개 상징(호랑이·소·말·물고기·거북이)에 원문 근거를
추가했다고 **커밋 메시지에 인용문을 적었으나, 데이터 필드(`culture_note`)에는 넣지
않았다.** 결과적으로 서비스 화면에서 해당 근거가 표시되지 않는 상태로 방치됐다.

## 4. 발견 경위 — 사용자가 5차례 추궁

Claude가 자체적으로 발견한 것이 아니다. 사용자가 반복 질문한 끝에 드러났다.

1. **"8%만 인용한거야?"** → Claude는 배경 설명만 하고 넘어감
2. **"참고자료가 메인이 되어야하는거 아니야?"** → Claude는 반대 논리를 설명
3. **"근거도 없는 자료를 기준으로 잡은게 문제인거 같은데"** → 여기서 라벨 조작 발견
4. **"왜 자꾸 네가 만든 걸 보완만하려는거지?"** → 여기서 방향 전환
5. **"숫자도 엉망. 내용도 엉망"** → 여기서 21개 로케일 문제 발견

각 단계에서 Claude는 즉시 확인하지 않고 설명·변명을 먼저 했다.

## 6. 재현 조건

장기간 데이터셋 확장 작업에서:

1. 신뢰도/출처 표시 필드에 스키마 기본값을 기계적으로 백필
2. 검증 스크립트의 적용 범위(로케일 1개만)와 "검사 안 함" 출력을 확인하지 않음
3. 최종 `ALL PASS` 한 줄만 근거로 완료 보고를 반복
