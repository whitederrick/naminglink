# Naming-Link 작업 메모리

마지막 갱신: 2026-08-11

## 애드센스 재심사 — 현재 합의 (2026-08-10)

- 현재 HEAD 기준으로 **코드상 재심사 블로커는 없다.** 과거 검토 메모
  `docs/issues/ADSENSE_NEXT_SESSION.md`는 `5656343` 시점 기준이며, 이후 `a27b696`·
  `7d4b290`·`58df928`에서 해결·재결정됐다. 해당 문서는 `SUPERSEDED` 기록으로만 보고 현재
  검토 기준으로 사용하지 않는다.
- 전역 AdSense 로더는 제거됐다. 로더는 `AdBanner`가 있는 네 결과 화면에서만 지연 로드되며,
  `ko` + 실제 복원 결과(`ready && stored`, 발음 결과는 `ready && currentStored`) + 유효 슬롯일
  때만 요청할 수 있다.
- 로그인·요금·주문·가이드·404·빈 결과와 `ko` 외 미검수 로케일에는 광고 요청이 없어야 한다.
  `HUMAN_REVIEWED_LOCALES`의 현재 값은 `{ko}`다.
- review 모드에서도 위 조건을 만족하는 한국어 실제 결과 배너는 유지하기로 했다. 이 결정을
  유지하는 동안 AdSense CSP도 열어 둔다. CSP만 `adsLive`로 닫으면 이 방침과 충돌한다.
- 사이트 연결은 `google-adsense-account` 메타 태그와 `/ads.txt`로 유지한다.
- `/stamp-order`는 상품 설명·판매 중단 사실·문의 경로를 제공하고 광고가 없으므로 색인을
  유지한다. sitemap 우선순위 `0.8 → 0.4`는 비차단 권장 작업이다.
- 전 상품 판매 중지 상태에서는 요금 금액과 도장 신청서를 노출하지 않는다. 부분 판매 시 한
  문단의 미판매 가격이 함께 남을 수 있는 문제는 재심사 블로커가 아니지만, 첫 상품 활성화 전에
  필터와 회귀 검사를 보완한다.
- 재심사 전 남은 필수 작업은 **운영 배포 후 실제 브라우저 실측**이다. 각 화면을 3~5초 기다린
  뒤 `pagead2.googlesyndication.com`·`googleads.g.doubleclick.net`·`securepubads`·
  `googletag`·`fundingchoices` 요청과 동적 `adsbygoogle` 자리를 확인한다.
  - 없어야 함: 로그인·요금·주문·가이드·404·빈 결과·비한국어 화면
  - 대조군: `ko` + 실제 복원 결과 + 유효 슬롯에서는 의도한 광고 요청 확인
  - 모든 검사는 출력 문구뿐 아니라 프로세스 종료 코드까지 확인한다.

## 현재 운영 상태

- 운영 URL은 `https://naming-link.com`이다. 라이브 도메인의 원본은
  `packages/core/src/self-ads.ts`의 `SELF_AD_SERVICES`다. `naminglink.vercel.app`은
  `NEXT_PUBLIC_SITE_URL`이 비었을 때의 폴백일 뿐이며, 그 값이 비면 `robots.txt`가
  `Disallow: /`로 떨어져 크롤링이 통째로 막힌다 — **화면으로는 티가 안 난다.**
- 프리미엄 상품은 실제 후보 확보 수에 따라 제공하며 `최대 5개/최대 10개`로 표시한다.
- 결제 화면은 현재 제공 후보 수를 표시하고 화면·PDF·후보 상세 분석의 후보 수와 순서를 강제로 일치시킨다.
- 안덕규 + 돌림자 `奎` 회귀 결과는 `德奎` 1개이다.
  - `徳`: 본자 `德`의 약자 설명뿐이므로 독립 후보 제외
  - `㯖`: `덕,적`은 뜻이 아닌 음가 목록이므로 제외
  - `悳`: `德`과 의미가 같아 중복 정리
- 돌림자 강제 고정, PUA·부정 의미·성별 조건 충돌·불충분 의미 필터와 한국 국자 배지를 적용했다.
- 결과 화면의 `입력 수정`은 서비스 입력 URL로 이동하며 직전 입력값을 복원한다.
- 로컬 개발 환경은 무료 일일 한도를 차감하지 않는다.
- 로컬 서버는 포트 `3001`이며 사용자가 직접 관리한다. 임의로 시작·종료하지 않는다.

## 결제 구조 — 2026-07-29 확정

- **국내는 토스페이먼츠 직접 연동**이다(`apps/naminglink/src/lib/toss.ts`).
- **포트원은 해외 페이팔 전용**이다(`lib/portone.ts` · `NEXT_PUBLIC_PORTONE_CHANNEL_KEY_PAYPAL`).
  포트원 경유 국내 카카오페이 채널은 심사가 취소돼 쓰지 않는다. 단일 채널 키 폴백도 지웠다 —
  **국내 주문이 포트원으로 떨어지는 경로를 다시 만들면 안 된다.**
- 구매 노출은 **상품 `enabled` AND 결제 키**로 판정한다. 키 없이 켜 두면 죽은 버튼이 된다.

셋은 서로 독립이라 어느 것이 먼저 풀리든 상관없다. 사슬은 `docs/POST_LAUNCH_CHECKLIST.md`에 있다.

| | 기다리는 것 | 풀리면 열리는 것 |
| --- | --- | --- |
| **A** 애드센스 | naming-link 심사 결과 | 인연링크 광고 · 지표 초기화 |
| **B** 국내 결제 | 토스 키 · 통신판매업 신고번호 | 상품 판매 개시 · 엄격 CSP |

`PREMIUM_TEST_SECRET` 헤더가 맞아야 열린다(`lib/premium-test-access.ts`) — 플래그만 남아도
무단 개방되지 않는다.
